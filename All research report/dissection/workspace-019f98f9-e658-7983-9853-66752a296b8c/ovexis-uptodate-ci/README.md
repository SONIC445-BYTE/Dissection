## Confidence Discipline (used in every file)

| Label | Meaning |
|---|---|
| 🟢 **Confirmed** | Directly evidenced by a primary or reputable public source (company pages, press releases, filings, app store listings, job posts, peer-reviewed papers, Reddit/X firsthand reports). Source cited in the Evidence Register (file 27). |
| 🟡 **Strong Inference** | Logically entailed by confirmed evidence (e.g., architecture implied by job requirements, pricing mechanics implied by multiple user reports). |
| 🔴 **Speculation** | Plausible but unverified model of reality. Used sparingly, always flagged. |
| ⚪ **Cannot Verify** | Public record is silent or contradictory; we state this explicitly and never guess. |
