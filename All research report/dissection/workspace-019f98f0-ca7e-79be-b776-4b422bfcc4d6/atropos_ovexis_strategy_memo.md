# Ovexis Strategy Memo — Lessons from Atropos Health

## Strategic thesis

🟡 Atropos Health is attempting to own the clinical evidence-generation layer. Ovexis should not copy this head-on. Ovexis should build a broader longitudinal health intelligence layer that combines patient-owned records, consent, labs, wearables, clinical evidence, and clinician workflow.

## What Ovexis should copy

🟡 Evidence-gap category narrative; federated architecture; evidence quality scoring; clinician review; RAG + generated evidence; reusable evidence library; rerun loops; workflow integrations; publications as trust; advisory boards; cloud marketplace channels; transparent clinical disclaimers.

## What Ovexis should improve

🟡 FHIR-native public API, patient consent controls, patient-facing evidence summaries, wearable/lab integration, data lineage, causal assumptions, model cards, bias diagnostics, uncertainty visualization, India/ABDM-native exchange, open developer sandbox, multilingual explanations, outcome follow-up loops, and governance console.

## What Ovexis should ignore

🟡 Avoid overclaiming diagnosis, black-box evidence badges, PDF-only outputs, generic chatbot UX, opaque pricing, single-cloud dependence, single-LLM dependence, raw-data-first monetization, and enterprise-only distribution.

## Blue-ocean wedge

🔴 Build the first patient-consented longitudinal evidence network: patient record vault + clinician workspace + AI evidence copilot + consented research/evidence network.

## Recommended MVP

1. 🟡 Longitudinal Health Graph: FHIR/ABDM ingestion, labs, medications, diagnoses, procedures, notes, and patient-reported outcomes.
2. 🟡 Evidence Copilot: literature RAG + patient record context + evidence applicability score.
3. 🟡 Patient App: personal timeline, lab/wearable trends, consent controls, share-with-doctor workflow.
4. 🟡 Clinician Workspace: timeline, similar-patient evidence, uncertainty, and clinician-reviewed next actions.
5. 🟡 Developer API: OpenAPI, OAuth2/OIDC, webhooks, FHIR Bulk Data, synthetic sandbox.

## Recommended GTM

🟡 Start with premium preventive clinics, specialty clinics, employer clinics, diagnostic networks, and India/ABDM-aligned partners before large hospitals.

## Recommended moat

🟡 Consented longitudinal data moat + outcome loop + trust/evaluation moat + developer ecosystem + provider/patient network effects.

## Recommended AI architecture

🟡 Multi-agent architecture: ingestion agent, normalization agent, literature retrieval agent, patient context agent, causal critique agent, safety agent, clinician-note agent, patient-explanation agent, evaluation agent.

## Recommended pricing

🟡 Consumer freemium record vault; paid longitudinal insights; clinic per-provider subscription; per-active-patient monitoring; enterprise platform fee; life-sciences evidence packages under consent governance.

## 36-month roadmap

- 🟡 0–6 months: record vault, lab import, wearable sync, consent, clinician summary.
- 🟡 6–12 months: Evidence Copilot, clinician workspace, API sandbox, first specialty pathway.
- 🟡 12–24 months: outcomes loop, clinic network, payer/lab partnerships, ABDM launch, public model/evidence evals.
- 🟡 24–36 months: federated network, registry-as-a-service, trial matching, enterprise governance.
