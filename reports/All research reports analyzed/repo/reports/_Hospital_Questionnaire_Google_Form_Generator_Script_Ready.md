## 3 Simple Steps to Create Your Form:

### Step 1: Open Google Apps Script Editor
Go to **https://script.google.com** and click **"New Project"**

### Step 2: Paste the Script
- Delete any existing code in the editor
- Open the Google Doc above, select ALL text (Ctrl+A), and copy it (Ctrl+C)
- Paste it into the Apps Script editor (Ctrl+V)

### Step 3: Run It
- Click the **▶ Run** button (or select Run → Run function → "createHospitalForm")
- Authorize the script when prompted (it needs permission to create forms)
- Check the **Execution log** at the bottom — it will show the URL of your new Google Form

## What You Get:
✅ A fully-branched Google Form with **9 sections**
✅ Section 1: Consent + Metadata + 18 Universal Questions + 10 JARVIS Probes + Role Branching
✅ Sections 2–9: Role-specific questions (Consultants, Jr Residents, Nurses, Lab Techs, Pharmacists, Support Staff, Admin, IT)
✅ **Automatic branching**: selecting a role sends the respondent ONLY to their relevant section
✅ Each role section submits the form after completion — no irrelevant questions

The form will appear in your Google Drive once created.
