# FUNCTION HEALTH — COMPETITIVE INTELLIGENCE EVIDENCE REGISTER

## Methodology Note
This register documents every evidential claim used in the Ovexis strategic analysis of Function Health. All claims are categorized as:

- 🟢 Confirmed — Directly observed from primary source (website, API docs, press release, regulatory filing, user-facing interface)
- 🟡 Strong Inference — Logically derived from multiple confirmed sources with high confidence
- 🔴 Speculation — Strategic inference without direct evidence; clearly labeled
