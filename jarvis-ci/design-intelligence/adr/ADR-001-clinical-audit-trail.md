## Context

JARVIS contains **zero** healthcare functionality today — verified against the
repository, not inferred. No FHIR, no HL7, no ABDM, no patient model, no consent
handling, and no audit trail.

The corpus supplies a directly analogous case. A well-funded L3 infrastructure
company named healthcare as a target vertical and shipped no compliance posture
at all `[MEM0-C-042, MEM0-C-044]`. The consequence recorded in the failure library
(FAIL-005) is that regulated verticals became structurally closed to it — not
because the product was weak, but because the architecture froze before the
requirement was understood.

JARVIS is currently in the same starting position, with one advantage: **the
failure is documented in advance.**

## Decision

Architect the clinical audit trail **into the action pipeline now**, before any
clinical write path exists.

Every read and write of clinical data emits an immutable record: who, what, when,
why, which source system, which consent grant.

## Alternatives considered

### A. Architect in now *(recommended)*
- **Pros** — cheap while the write paths are few; becomes a regulatory moat
  (MOAT-003, copy resistance *strong*, ~24 months); avoids retrofit entirely
- **Cons** — slows current velocity; work with no immediate user-visible value

### B. Retrofit later
- **Pros** — faster now
- **Cons** — cost grows with every adapter added; touching every write path after
  the fact; may require re-certification; **cost curve is exponential**

### C. Rely on host-system audit
- **Pros** — zero build
- **Cons** — JARVIS actions occur *outside* the EMR's audit boundary. The one
  thing that must be traceable — what the agent did autonomously — is precisely
  what a host-system trail cannot see.

## Consequences

**Positive** — unblocks regulated-market entry; supplies the provenance requirement
from `05-healthcare-ontology.md` §5.2; foundation for MOAT-003; converts an
unglamorous obligation into a defensible position.

**Negative** — one-way. Once the audit format is consumed by external systems it
becomes an interface contract. Adds a write-path cost to every action.

**Neutral** — does not require choosing a storage backend, so it is separable from
DEC-001.

## Reversal trigger

Revisit if a regulatory change makes host-system audit legally sufficient for
autonomous agent actions, **or** if JARVIS abandons clinical write operations
entirely and becomes read/advisory only.

Absent one of those two events, this decision stands.
